# 逆行列計算機

ブラウザだけで動く、逆行列を求める静的 Web アプリです。

## 機能

- 2x2 から 6x6 までの正方行列に対応
- 小数・整数・分数入力に対応
- ガウス・ジョルダン法で逆行列と行列式を計算
- 結果を分数または小数で表示
- 特異行列の場合はエラーを表示
- CSV貼り付けと計算結果のCSVコピーに対応
- 画面上のテンキーで数字・マイナス・分数を入力（スマホ対応）

## ローカルで開く

`index.html` をブラウザで開くだけで使えます。

## GitHub Pages

`main` ブランチのルートディレクトリを GitHub Pages で公開します。
